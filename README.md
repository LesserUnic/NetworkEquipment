# Система учета сетевого оборудования

## Описание
Система для управления сетевым оборудованием с веб-интерфейсом, базой данных и поиском по фильтрам.

## Функционал
1. Веб-интерфейс для просмотра и добавления устройств
2. Хранение технических характеристик оборудования
3. Хранение оцифрованных документов и накладных
4. Поиск и фильтрация оборудования

## Технологии
- Backend: Python + Flask
- Database: SQLite (с возможностью миграции на PostgreSQL)
- Frontend: HTML/CSS/JavaScript
- File Storage: Локальное хранилище документов

## Установка и запуск

```bash
pip install -r requirements.txt
python app.py
```

Доступ к веб-интерфейсу: http://localhost:5000
